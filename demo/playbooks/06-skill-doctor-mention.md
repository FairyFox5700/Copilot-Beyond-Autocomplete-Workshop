# Demo 6 — Skill Drift Check (skill-doctor, mention only)

> This is a link-and-narrate demo, not a live run — skill-doctor is not installed in this
> repository and installing it live is not worth the time in a 40-minute slot.

## Steps to show

1. Have the link open in a browser tab, ready to switch to: https://github.com/marketplace/actions/skill-doctor
2. Say the line below.
3. Switch to the tab for 3–5 seconds — just enough for the audience to see it exists — then switch back.
4. Do not install or run it live.

## Say this

> "There's a nice GitHub Action called skill-doctor that checks whether your instructions
> and skills have drifted from your actual codebase over time. The more drift it has,
> the harder it is for Copilot — and for you — to understand. I'll drop the link in chat."
