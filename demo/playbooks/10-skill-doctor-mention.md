# Demo 10 - Skill Health Check

## [skill-doctor documentation](https://github.com/marian2js/skill-doctor#readme)

## [Install Node.js LTS with npm and npx](https://nodejs.org/en/download)

## Verify prerequisites

```text
Check node --version, npm --version, and npx --version.
If any are missing, stop and report what needs to be installed.
```

## Install skill-doctor on demand

```text
Run npx -y skill-doctor@latest --version.
Do not add project dependencies or install the package globally.
```

## Scan repository skills

```text
Run npx -y skill-doctor@latest .github\skills from the repository root.
Report the score, errors, and warnings. Do not modify repository files.
```
